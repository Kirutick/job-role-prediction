UNDER THE HOOD

How the system works

Each step leads to a result from the existing application.

01

Input

Provide resume text, a PDF, or an image resume.

02

Text extraction

Read PDF content or prepare image content for OCR.

03

OCR

Tesseract OCR extracts readable text from image resumes.

04

Preprocessing

Normalize resume text for the saved vectorizer.

05

Machine learning

TF-IDF features are classified by the ResumeAtlas-trained model.

06

Skill extraction

Identify skills present in the supplied resume content.

07

Screening

Generate the application's separate heuristic breakdown.
